3. Описание сервиса

Neo 4D Wall предоставляет расширенные обои для персонализации личных устройств, дополненные высококачественным 3D-параллаксом, видео, живыми эффектами, эффектами касания и эффектами по краям экрана.

Приложение включает следующие основные функции:

  • Библиотека обоев в выбранных категориях (Космос, Природа, Животные, Автомобили, AMOLED, Абстракция и др.)
  • Обои с эффектами 3D-параллакса
  • Видеообои, включая настройку скорости
  • Редактор: инструмент настройки, позволяющий пользователям создавать собственные обои локально на своем устройстве (эффекты касания, эффекты лепестков, стиль «Светящиеся края» и эффекты рамки)
  • Автоматическая смена обоев: инструмент планирования, автоматически меняющий обои через выбранный интервал

Библиотека контента может состоять из визуальных материалов, подготовленных разработчиком, полученных из лицензированных источников и/или полученных в соответствии с условиями использования соответствующих сторонних инструментов. Контент, созданный с помощью Редактора, не загружается на серверы.

Приложение не требует создания учетной записи и не содержит рекламы.

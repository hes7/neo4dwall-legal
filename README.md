# Neo 4D Wall — Legal Documents & Support

Static, dependency-free GitHub Pages package generated from the app's versioned legal JSON files.

## Play Console URLs after publication

- Privacy policy: `https://<github-user>.github.io/<repository>/privacy.html`
- Support: `https://<github-user>.github.io/<repository>/support.html`
- Data deletion information: `https://<github-user>.github.io/<repository>/data-deletion.html`
- Terms / EULA: `https://<github-user>.github.io/<repository>/terms.html`

## Publish

1. Create a dedicated public repository for this folder. Do not publish the Android source repository just to host these pages.
2. Push this folder's contents to the repository's default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, the default branch, and **/(root)**.
4. Wait for the Pages deployment, then open every URL above in a signed-out/private browser window.
5. Enter the verified public URLs in Play Console.

No analytics, cookies, forms, remote fonts, or external JavaScript are used by this site.
